# Storylines (autonomous run: recommendation built, the others kept for a later switch)

1. **One session, one window (picked).** Device: the product does the work. Form: one frame that rebuilds:
   a single app window stays put while the real screen recordings change inside it, with one caption per
   step (library → topic + related → map → search), then an end card. Look: the app's own graphite and
   ember, Inter. Sound: none (README GIF). Why: shows the real UI at a readable size, no invented screens.
2. **The result first.** Opens on the zoomed-in map of a real library, pulls back to reveal the app, then
   the features. Stronger hook, but the map alone does not explain what the app is in the first seconds.
3. **One object across apps.** A pasta reel saved on Instagram travels into SavedMap and is found again by
   searching "pasta recipe". Clear story, but needs a capture of Instagram itself (not available offline).
